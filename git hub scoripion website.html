Simple setup

From download to first session.

No development tools needed. You'll just need the installer, your target hardware, and a compatible Windows PC.

01

Download

Click Download for Windows to get the latest Scorpion Defense installer from the official GitHub release.

02

Install

Run ScorpionDefenseSetup.exe and follow the on-screen instructions. Launch Scorpion Defense when installation is complete.

03

Connect & train

Turn on your compatible Scorpion Defense targets, connect to the master through the app, and select a training mode.

Before installing: Scorpion Defense requires its companion target hardware. This is an early Windows release. Because the installer may not yet be code-signed, Windows may display a publisher or SmartScreen warning. Verify that you obtained the installer from the official GitHub release. Test on additional PCs before a wide public rollout.
